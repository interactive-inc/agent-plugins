| 依頼・条件 | ガイド |
| --- | --- |

| 遅い画面・API・処理を調べて改善する | [性能改善](performance/index.md) |
| WordPress・plugin・theme・PHP の更新 | [WordPress / PHP](wordpress/index.md) |
| Orca への実装の引き渡しを明示された | [作業の引き渡し](handoff/index.md) |
| 既存の文書・構成を整理する | [保守](maintenance/index.md) |
